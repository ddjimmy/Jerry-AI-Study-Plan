# Parent Guide

[中文版本](PARENT-GUIDE.zh-CN.md)

The parent's job is to enforce consistency, not to become the AI instructor.

## Weekly Demo Questions

Ask these five questions every Saturday:

1. Show me what you built.
2. What problem does it solve?
3. What was the hardest bug?
4. What did you change to improve it?
5. What are you building next week?

## Weekly Score (100 points)

| Category | Points |
|---|---:|
| Daily coding completed | 25 |
| Git commits | 15 |
| Project runs | 25 |
| Can explain the code | 20 |
| README / documentation | 5 |
| Saturday demo | 10 |

### Interpretation

- 90–100: Excellent
- 80–89: Good
- 70–79: Needs improvement
- Below 70: Week should be revisited

## What Not to Measure

Do not primarily measure:

- number of videos watched,
- certificates earned,
- number of hours with a course open.

Measure:

- what was built,
- whether it works,
- whether the student can explain it,
- and whether the project improved during the week.
