# Jerry AI 学习计划

[English Version](README.md)

这是一个为 CEGEP 计算机科学专业学生设计的 12 周 AI 实践学习计划。

目标不是继续收集入门证书，而是通过一套可重复的循环，培养真正的工程能力：

**学习 -> 构建 -> 调试 -> 讲解 -> 改进 -> 演示**

## 核心原则

- 每周学习 5 天。
- 每个学习日投入 60-90 分钟。
- 大约 30% 的时间学习知识，70% 的时间动手编程。
- 每个学习日都应产出代码、笔记或一次 Git commit。
- 每周都以一个可以运行的成果演示结束。
- AI 助手可以讲解、审查代码、协助调试和提供提示，但学生必须理解代码。
- 如果无法解释重要代码，这项任务就不算完成。

## 12 周路线图

| 周次 | 学习重点 | 主要成果 |
|---|---|---|
| 1 | 面向 AI 的 Python | 游戏数据统计分析器 |
| 2 | NumPy、Pandas 与数据可视化 | 游戏表现仪表板 |
| 3 | 机器学习基础 | 第一组分类模型 |
| 4 | 模型评估 | 模型对决 |
| 5 | 机器学习项目 | AI 游戏表现教练 |
| 6 | PyTorch 基础 | 第一个神经网络 |
| 7 | 计算机视觉 | 图像分类应用 |
| 8 | 目标检测 | 自定义 YOLO 检测器 |
| 9 | 大语言模型应用 | AI 游戏教练 v2 |
| 10 | 嵌入向量与 RAG | AI 学习伙伴 |
| 11 | Streamlit 与 FastAPI | AI 应用程序 |
| 12 | 综合项目 | AI Game Lab |

详细计划请参阅 [12-WEEK-ROADMAP.zh-CN.md](12-WEEK-ROADMAP.zh-CN.md)，每日任务请查看 [weeks/zh-CN/](weeks/zh-CN/)。

## 语言策略

工程实现和 GitHub 作品集展示以英文为主。重要学习材料同时提供完整的简体中文版本，方便学习、讨论和家长复盘。可执行源代码只保留一份，并使用英文命名和英文注释。

## 最终目标

完成 12 周学习后，学生应能独立完成以下流程：

**问题定义 -> 数据集 -> 数据清理 -> 模型训练 -> 模型评估 -> 改进 -> 保存模型 -> API/UI -> GitHub 文档**

最终综合项目是 **AI Game Lab**，它将数据分析、机器学习、计算机视觉、大语言模型和简单的 Web 应用整合在一起。
