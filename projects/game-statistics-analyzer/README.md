# Game Statistics Analyzer v1

[中文版本](README.zh-CN.md)

## Purpose

Game Statistics Analyzer v1 is the Week 1 hands-on project in the Jerry AI Study Plan. It turns a small CSV dataset of game sessions into terminal statistics and a JSON summary.

This is a starter project. It intentionally contains the dataset and folder structure, but not the finished Python solution. Jerry writes the scripts during the five daily missions in [Week 1](../../weeks/en/week01.md).

## Week 1 Learning Goals

- Verify a Python, Git, VS Code, and virtual-environment workflow.
- Use lists, dictionaries, loops, and conditions to analyze in-memory data.
- Refactor logic into focused functions with parameters and return values.
- Read CSV and write JSON with Python's standard library.
- Handle division by zero, invalid input, and one missing accuracy value intentionally.
- Build, test, explain, and commit a complete command-line program.

## Project Layout

```text
game-statistics-analyzer/
├── README.md
├── README.zh-CN.md
├── data/
│   └── game_sessions.csv
├── src/
│   ├── hello_ai.py       # Jerry creates this on Day 1
│   ├── player_stats.py   # Jerry creates this on Day 2
│   ├── csv_analyzer.py   # Jerry creates this on Day 4
│   └── analyzer.py       # Jerry creates this on Day 5
└── output/
    └── summary.json      # Generated by the student program
```

The committed `.gitkeep` files preserve the empty `src/` and `output/` directories until Jerry creates the scripts and generated output.

## Run the Day 4 Script

After Jerry creates `csv_analyzer.py`, run it from the repository root:

```bash
python projects/game-statistics-analyzer/src/csv_analyzer.py
```

Or run it from this project directory:

```bash
python src/csv_analyzer.py
```

The script should read `data/game_sessions.csv` and write `output/summary.json`. Design file paths relative to the script or project directory so both commands work.

## Run the Day 5 Script

From the repository root:

```bash
python projects/game-statistics-analyzer/src/analyzer.py
```

Or from this project directory:

```bash
python src/analyzer.py
```

## Expected Results

The final terminal output should be:

```text
Games analyzed: 15
Average kills: 14.00
Average deaths: 8.60
Average accuracy: 41.57%
Best game: G008
Worst game: G014
Missing accuracy values: 1
```

The generated `output/summary.json` must contain these keys:

```text
total_games
average_kills
average_deaths
average_accuracy
missing_accuracy_count
```

Bonus result: `Win rate: 60%`.
