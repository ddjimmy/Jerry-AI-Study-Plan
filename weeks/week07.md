# Week 7 — Computer Vision

## Goal
Build an **Image Classifier App**.

## Day 1
Explore:
- width
- height
- channels
- pixels

## Day 2
Learn the high-level CNN idea:
Image → filters/features → classification.

## Day 3
Train a small classifier. Choose a dataset/theme you actually like.

## Day 4
Test on images you supply yourself.

## Day 5
Create a small app that accepts an image and shows:
- predicted class
- confidence

### Weekly Demo
Test the classifier on a new image it has never seen.
