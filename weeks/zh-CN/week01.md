## 目标

构建**游戏数据统计分析器 v1（Game Statistics Analyzer v1）**，并养成使用 Git/GitHub 的习惯。

## 第 1 天：开发环境与 Git

- 确认 Python 和 VS Code 可以正常使用。
- 安装并使用 Jupyter。
- 克隆本仓库。
- 创建 `work/week01/` 目录。
- 运行一个简单的 Python 程序。
- 完成第一次个人学习 commit。

### 完成标准

- Python 可以在本地运行。
- 仓库已成功克隆。
- 今天的学习成果已经形成一次 commit。

## 第 5 天：迷你项目

构建**游戏数据统计分析器 v1**。

- 游戏总场数
