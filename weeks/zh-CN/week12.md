# 第 12 周综合项目：AI Game Lab

[English Version](../en/week12.md)

## 规则

本周不要学习新框架，重点是完成和打磨现有成果。

## 模块 1：游戏表现分析器

CSV -> Pandas -> 图表 -> 机器学习 -> 预测

## 模块 2：截图分析器

截图 -> 目标检测 -> 物体与置信度

## 模块 3：AI 教练

游戏表现数据 + 检测数据 -> 大语言模型 -> 建议

## 模块 4：用户界面

创建一个连贯、完整的用户体验。

## 最终要求

- 可以运行的应用程序
- 清晰的仓库结构
- 可复现的安装和运行步骤
- README
- 架构说明
- 截图
- 模型结果
- 已知限制
- 未来改进方向

## 最终演示问题

1. 这个项目解决了什么问题？
2. 数据如何在系统中流动？
3. 你做出了哪些模型选择？
4. 你如何评估这些模型？
5. 开发过程中哪些尝试失败了？
6. 下一步你会改进什么？
