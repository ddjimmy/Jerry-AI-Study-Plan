# 12-Week AI Roadmap

[中文版本](12-WEEK-ROADMAP.zh-CN.md)

## Phase 1 — Python + Data

### Week 1 — Python for AI
Build a **Game Statistics Analyzer**.

Skills:
- Python data structures
- functions
- CSV/JSON
- Git/GitHub
- basic program organization

### Week 2 — NumPy + Pandas + Visualization
Build a **Game Performance Dashboard**.

Skills:
- NumPy arrays and statistics
- Pandas DataFrames
- filtering/grouping
- missing values
- Matplotlib
- evidence-based observations

## Phase 2 — Machine Learning

### Week 3 — First ML Models
Train classification models using scikit-learn.

Skills:
- features and labels
- train/test split
- Logistic Regression
- Decision Trees
- Random Forest

### Week 4 — Model Evaluation
Build a **Model Battle** comparing multiple algorithms.

Skills:
- accuracy
- precision
- recall
- F1
- confusion matrix
- overfitting
- underfitting

### Week 5 — ML Project
Build **AI Gaming Performance Coach**.

Inputs may include:
- session length
- accuracy
- reaction time
- wins/losses
- kills/deaths
- sleep hours

Goal:
Predict good/bad sessions and explain the result.

## Phase 3 — Deep Learning + Computer Vision

### Week 6 — PyTorch Fundamentals
Build the first neural network.

Skills:
- tensors
- model layers
- loss
- gradients
- backpropagation
- optimizer
- training loop
- saving/loading models

### Week 7 — Computer Vision
Build an **Image Classifier App**.

Skills:
- image representation
- channels/pixels
- CNN concepts
- training and validation
- inference on personal images

### Week 8 — Object Detection
Build a **Custom YOLO Detector**.

Skills:
- classification vs detection
- bounding boxes
- pretrained inference
- video/webcam inference
- small custom dataset
- model training and validation

## Phase 4 — LLM Applications

### Week 9 — LLM Development
Build **AI Game Coach v2**.

Skills:
- prompts
- context
- structured output
- Python API integration
- combining ML output with LLM explanations

### Week 10 — Embeddings + RAG
Build an **AI Study Buddy**.

Skills:
- chunking
- embeddings
- semantic search
- retrieval
- RAG
- question answering over personal notes
- quiz generation

## Phase 5 — AI Engineering

### Week 11 — App + API
Turn models into an application.

Skills:
- Streamlit
- file upload
- forms
- model inference
- FastAPI
- REST endpoints
- simple app architecture

### Week 12 — Capstone: AI Game Lab

Combine:

1. Game Performance Analyzer
2. Screenshot/Object Detector
3. AI Coach
4. Web UI

Final repository should include:

```text
ai-game-lab/
├── README.md
├── data/
├── notebooks/
├── src/
├── models/
├── api/
├── app/
└── requirements.txt
```

The student should be able to explain the architecture, dataset, model choices, evaluation results, limitations, and next improvements.
