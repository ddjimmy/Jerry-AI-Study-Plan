# Jerry AI Study Plan

A 12-week hands-on AI learning program for a CEGEP Computer Science student.

The goal is not to collect more beginner certificates. The goal is to build real engineering ability through a repeatable loop:

**Learn → Build → Debug → Explain → Improve → Demo**

## Core Principles

- Study 5 days per week.
- 60–90 minutes per study day.
- Roughly 30% learning and 70% hands-on coding.
- Every study day should produce code, notes, or a Git commit.
- Every week ends with a working demo.
- AI assistants may explain, review, debug, and give hints, but the student must understand the code.
- If important code cannot be explained, the task is not considered complete.

## 12-Week Roadmap

| Week | Focus | Main Deliverable |
|---|---|---|
| 1 | Python for AI | Game Statistics Analyzer |
| 2 | NumPy, Pandas, Visualization | Game Performance Dashboard |
| 3 | Machine Learning Basics | First Classification Models |
| 4 | Model Evaluation | Model Battle |
| 5 | ML Project | AI Gaming Performance Coach |
| 6 | PyTorch Fundamentals | First Neural Network |
| 7 | Computer Vision | Image Classifier App |
| 8 | Object Detection | Custom YOLO Detector |
| 9 | LLM Applications | AI Game Coach v2 |
| 10 | Embeddings and RAG | AI Study Buddy |
| 11 | Streamlit and FastAPI | AI Application |
| 12 | Capstone | AI Game Lab |

See [12-WEEK-ROADMAP.md](12-WEEK-ROADMAP.md) for the detailed plan and the `weeks/` folder for day-by-day tasks.

## End Goal

After 12 weeks, the student should be able to independently work through:

**Problem → Dataset → Data Cleaning → Model Training → Evaluation → Improvement → Saved Model → API/UI → GitHub Documentation**

The capstone project is **AI Game Lab**, combining data analysis, machine learning, computer vision, LLMs, and a simple web application.
